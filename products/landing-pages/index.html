How to use a template

  1. Open a template above and view source (or grab it from the GitHub repo).
  2. Save the single index.html file — all CSS is inline in the <head>.
  3. Find & replace the business name, copy, prices, and contact details.
  4. Adjust the color scheme by editing the :root CSS variables (e.g. --primary).
  5. Deploy free: drag the folder into Netlify Drop, Cloudflare Pages, or push to GitHub Pages.
