# Festival Greeting Generator

Create beautiful festival greeting cards with custom text in English and Hindi,
add your logo, and download as a high-resolution PNG — no signup, no watermarks,
100% free and client-side.

## Features

- **6 Festival Templates:** Diwali, Holi, Eid, Christmas, New Year, Winter
- **Bilingual Text:** English + हिन्दी (Devanagari script)
- **Logo Upload:** Add your logo or decorative image
- **Color Customization:** Choose from curated palettes or set custom colors
- **Download as PNG:** High-resolution export with no watermarks
- **100% Client-Side:** Your images never leave your browser

## Usage

1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari)
2. Select a festival template from the **Templates** tab
3. Customize text in **Editor** tab:
   - Edit English message
   - Edit Hindi message (हिन्दी संदेश)
   - Adjust font size and family
   - Pick colors from presets or use custom color pickers
   - Upload a logo and position it with sliders
4. Switch to the **Preview** to see real-time updates
5. Click **Download as PNG** to save your greeting

No dev server needed — just open the file directly.

## Technology

- Vanilla HTML5, CSS3, and JavaScript (no frameworks)
- Canvas API for rendering
- Google Fonts: Roboto (UI + English text) and Hind (Hindi/Devanagari text)
- Drag-and-drop file upload

## Deploy

This is a static site — deploy to any static hosting:

- **Cloudflare Pages:** Drag & drop the `products/festival-greeting/` folder
- **GitHub Pages:** Enable Pages in repo settings, set `/products/festival-greeting/` as source
- **Vercel:** `vercel --cwd products/festival-greeting`
- **Netlify:** Drag & drop the folder
