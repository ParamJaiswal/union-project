Catalogue PDF Builder

📇 Catalogue PDF Builder is a free, open-source web app that lets you create professional product catalogues and export them as PDFs — all in your browser, no backend required.

Features:

  • Add products with name, price, SKU, description, and images
  • Upload images from URL or file
  • Import/export catalogue data via CSV or JSON
  • Real-time preview of catalogue layout
  • Download as high-quality PDF
  • 100% client-side — your data never leaves your browser

CSV Format:

name,price,sku,image,description
Handcrafted Lamp,499,SKU-001,https://example.com/lamp.jpg,Beautiful lamp
